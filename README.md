## 🧭 项目简介

**Sunchha**（取自闽南语“巡查”，发音为 *Sûn-chhá*）是一款专为 **网络设备自动化巡检** 设计的工具。

它诞生于对传统巡检方式的反思：  
> 大量重复、机械、低效的人工操作，本不该成为工程师的负担。

Sunchha 希望通过自动化手段，将繁琐工作交给机器完成，让你把时间留给真正重要的事情：  
🔹 技术研究  
🔹 安全防护  
🔹 网络优化与运维决策
